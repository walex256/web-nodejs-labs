# Лабораторные работы по серверной веб-разработке

Дик Алексей Васильевич, ИТ2403. Node.js 24 и Fastify.

Структура проекта и оформление главной страницы основаны на [шаблоне web-nodejs-labs](https://gitverse.ru/Umi_co/web-nodejs-labs).

## Запуск

С Docker из корня репозитория:

```sh
docker compose -f docker-compose.local.yml up --build -V
```

С Node.js 24 без Docker:

```sh
cd backend
npm ci
npm start
```

Откройте [главную страницу](http://localhost:3000/) или [лабораторную №7](http://localhost:3000/lab7/).
Для разработки с автоматическим перезапуском сервера используйте `npm run dev` в каталоге `backend`.

## Лабораторная работа №7

- `/lab7/task1/` — калькулятор с четырьмя операциями на сервере.
- `/lab7/task2/` — форма получения инициалов и статуса участия в проекте.
- `/api/lab7/` — API заданий и примеры из методички. Ошибки ввода возвращаются со статусом 400 и полем `error`.

API лабораторных работ размещается в `backend/src/routes/`, страницы — в `public/`.

## Лабораторная работа №8

Откройте [страницу ЛР №8](http://localhost:3000/lab8/). На ней доступны пример со списком
пользователей, форма сохранения анкет, генерация JSON со сборными и стадионами и таблица
48 матчей ЧМ-2022.

Записи сохраняются локально в `backend/data/lab8/users.json` и `backend/data/lab8/task1.json`.
Эти файлы создаются при первой записи и исключены из Git. Данные матчей можно пересоздать
кнопками в заданиях 2 и 3 в этом порядке.

Для проверки API первого задания выполните `npm test` в каталоге `backend`.

## Лабораторная работа №9

Выполните из корня проекта:

```sh
docker compose -f docker-compose.local.yml up --build -V
```

Откройте [ЛР №9](http://localhost:3000/lab9/) или [Adminer](http://localhost:8080/).
Если порт 8080 занят статическими лабораторными, задайте `ADMINER_PORT=8081` в окружении
Docker Compose и откройте [Adminer на порту 8081](http://localhost:8081/).
Для Adminer выберите PostgreSQL, сервер `db`, базу `devdb`, логин `devuser` и пароль `devpass`.
На новом томе `backend/sql/lab9.sql` автоматически создаёт схему `lab9`, таблицу товаров
и добавляет 15 примеров. При первом запросе к API приложение также запускает этот SQL, если таблицы ещё нет.
Повторное выполнение сохраняет существующий каталог.

При запуске Node.js на компьютере используйте `localhost` вместо `db` в `.env.local`.
Docker Compose использует `backend/.env.local.example` как настройки локальной базы.
При необходимости значения можно переопределить в `backend/.env.local`.
На учебном сервере используйте предоставленный `DATABASE_URL`. Если пользователь приложения
не может создавать таблицы, выполните `backend/sql/lab9.sql` в той же базе через Adminer
с правами владельца и выдайте пользователю приложения права на каталог.
