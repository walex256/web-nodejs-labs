# Лабораторные работы по серверной веб-разработке

Дик Алексей Васильевич, ИТ2403. Node.js 24 и Fastify.

Структура проекта и оформление главной страницы основаны на [шаблоне web-nodejs-labs](https://gitverse.ru/Umi_co/web-nodejs-labs).

## Запуск

С Docker из корня репозитория:

```sh
docker compose -f docker-compose.local.yml up --build -V
```

С Node.js 24 без Docker:

```sh
cd backend
npm ci
npm start
```

Откройте [главную страницу](http://localhost:3000/) или [лабораторную №7](http://localhost:3000/lab7/).
Для разработки с автоматическим перезапуском сервера используйте `npm run dev` в каталоге `backend`.

## Лабораторная работа №7

- `/lab7/task1/` — калькулятор с четырьмя операциями на сервере.
- `/lab7/task2/` — форма получения инициалов и статуса участия в проекте.
- `/api/lab7/` — API заданий и примеры из методички. Ошибки ввода возвращаются со статусом 400 и полем `error`.

API лабораторных работ размещается в `backend/src/routes/`, страницы — в `public/`.
